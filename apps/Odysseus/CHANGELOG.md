# Changelog

All notable changes to Odysseus are recorded in this file.

Odysseus is versioned independently from other applications in the monorepo.

The current unreleased work is recorded under `Unreleased`. When a release is
made, those entries are moved into a dated version section and the repository
state is tagged using the Odysseus release tag convention.

Release tag format:

`odysseus-v<major>.<minor>.<patch>`
